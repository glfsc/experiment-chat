## 和 `documents/` 的区别

- `docs/项目复盘/`：面向学习、面试、作品集，经过整理，可提交到仓库；
- `documents/`：项目过程中的原始需求/方案/排期/实施报告，默认被 `.gitignore` 忽略，保留内部过程信息。

- 文档中的代码行号会随版本漂移；用函数名搜索更可靠。
- 涉及被试数据、内部联系人、服务器路径的内容，对外展示前请脱敏。
