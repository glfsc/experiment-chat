# 04 · 从零搭建骨架

> 目标：从一个空目录开始，按可验收的小步，搭出"一个问卷、一位被试、一道题、一次落库、刷新能恢复"的完整骨架。之后再加题型、管理端、导出、鉴权、打包。
>
> 核心方法：**垂直切片**。不要先写"用户模块、问卷模块、导出模块"这些横切层，而是先把一条最窄的端到端路径跑通，再横向扩展。

---

## 0. 先定"骨架"的边界

本篇搭的骨架只包含：

- 一个静态服务器 + `/api/health`；
- 一个 SQLite 库，两张核心表（问卷、会话）+ 消息/作答；
- 一种题型（打分题）+ 一条消息；
- 三个 API：`bootstrap`、`session`、`step`；
- 一个被试端页面：显示消息、渲染题卡、提交、刷新恢复；
- 一个极简管理端：用 JSON 文本框改问卷（先不做可视化编辑器）；
- 一个最小导出（CSV 或单 sheet xlsx）；
- 一个自检脚本。

**不包含**：10 种题型、题组、预览、二维码、便携包、多用户、复杂样式。这些是骨架跑通后的增量。

验收标准（全部满足才算骨架完成）：

1. `node server.js` 启动，`/api/health` 返回 `{ok:true}`；
2. 打开 `/chat?q=test0001`，能看到欢迎消息和一道打分题；
3. 点提交后，`responses` 表新增一行，时间戳齐全；
4. 刷新页面，已答的题以只读形式回放，当前题不重复；
5. 重复提交同一题，不产生第二行、不跳到下一题；
6. 改问卷内容后，已创建的会话仍按旧内容作答；
7. 导出文件能用 Excel 打开，一题一行；
8. `npm run check` 一条命令跑完上述断言。

## 2. Step 1：最小 HTTP 服务

`server.js`：

```js
'use strict';
const http = require('node:http');
const fs = require('node:fs');
const path = require('node:path');
const crypto = require('node:crypto');

const PORT = Number(process.env.PORT) || 3000;
const PUBLIC = path.join(__dirname, 'public');
const MIME = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.json': 'application/json; charset=utf-8'
};

function sendJson(res, status, payload) {
  res.writeHead(status, {
    'Content-Type': 'application/json; charset=utf-8',
    'Cache-Control': 'no-store'
  });
  res.end(JSON.stringify(payload));
}

function serveStatic(res, pathname) {
  const rel = pathname === '/' ? 'index.html' : pathname.replace(/^\/+/, '');
  const abs = path.resolve(PUBLIC, rel);
  // 防路径穿越：解码后的落点必须在 public/ 内
  if (abs !== PUBLIC && !abs.startsWith(PUBLIC + path.sep)) {
    res.writeHead(404); res.end('Not Found'); return;
  }
  fs.readFile(abs, (err, data) => {
    if (err) { res.writeHead(404); res.end('Not Found'); return; }
    res.writeHead(200, {
      'Content-Type': MIME[path.extname(abs).toLowerCase()] || 'application/octet-stream',
      'Cache-Control': 'no-store'
    });
    res.end(data);
  });
}

const server = http.createServer((req, res) => {
  let url, pathname;
  try {
    url = new URL(req.url, `http://localhost:${PORT}`);
    pathname = decodeURIComponent(url.pathname);
  } catch {
    return sendJson(res, 400, { error: 'bad_request' });
  }
  if (pathname === '/api/health') return sendJson(res, 200, { ok: true });
  serveStatic(res, pathname);
});

server.listen(PORT, () => {
  console.log(`http://localhost:${PORT}`);
});
```

验收：

```bash

curl -s http://localhost:3000/api/health
# {"ok":true}
```

> 【方法】先写健康检查。后面打包、部署、监控都靠它判断"服务活着吗"。

## 3. Step 2：数据层

`db.js`：

```js
'use strict';
const { DatabaseSync } = require('node:sqlite');
const fs = require('node:fs');
const path = require('node:path');

// 默认用项目根目录的 data.db；测试时可用 DB_PATH 指到临时库，避免污染开发数据
const DB_PATH = process.env.DB_PATH
  ? path.resolve(process.env.DB_PATH)
  : path.join(__dirname, 'data.db');
fs.mkdirSync(path.dirname(DB_PATH), { recursive: true });

const db = new DatabaseSync(DB_PATH);

db.exec(`
  PRAGMA journal_mode = WAL;
  PRAGMA synchronous = NORMAL;
  PRAGMA busy_timeout = 5000;
  PRAGMA temp_store = MEMORY;
`);

db.exec(`
CREATE TABLE IF NOT EXISTS questionnaires (
  id         TEXT PRIMARY KEY,
  title      TEXT NOT NULL,
  items_json TEXT NOT NULL DEFAULT '[]',
  created_at TEXT,
  updated_at TEXT
);

CREATE TABLE IF NOT EXISTS sessions (
  id                   TEXT PRIMARY KEY,
  questionnaire_id     TEXT NOT NULL,
  seq                  INTEGER,
  status               TEXT NOT NULL DEFAULT 'in_progress',
  items_json           TEXT NOT NULL DEFAULT '[]',
  started_at           TEXT,
  pending_presented_at TEXT,
  clear_seq            INTEGER DEFAULT 0
);

CREATE TABLE IF NOT EXISTS messages (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id TEXT NOT NULL,
  role       TEXT NOT NULL,
  content    TEXT NOT NULL,
  seq        INTEGER,
  created_at TEXT,
  item_id    TEXT
);

CREATE TABLE IF NOT EXISTS responses (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  session_id     TEXT NOT NULL,
  item_id        TEXT NOT NULL,
  unit_index     INTEGER NOT NULL DEFAULT 0,
  value          INTEGER,
  value_text     TEXT NOT NULL DEFAULT '',
  option_label   TEXT NOT NULL DEFAULT '',
  presented_at   TEXT,
  answered_at    TEXT,
  elapsed_ms     INTEGER
);

CREATE INDEX IF NOT EXISTS idx_responses_session ON responses(session_id, id);
CREATE INDEX IF NOT EXISTS idx_messages_session  ON messages(session_id, seq);
`);

// 种子：只在没有时插入，避免每次启动重复
```

## 4. Step 3：题目模型与会话计划

在 `db.js` 里加：

```js
const ITEM_TYPES = ['message', 'gate', 'confirm', 'debrief', 'group', 'rating', 'single', 'multi', 'text', 'rank'];
const QUESTION_TYPES = ['group', 'rating', 'single', 'multi', 'text', 'rank'];

function normalizeItems(raw) {
  if (!Array.isArray(raw)) return [];
  let qno = 0;
  return raw.map((item, index) => {
    const type = ITEM_TYPES.includes(item.type) ? item.type : 'message';
    const isQuestion = QUESTION_TYPES.includes(type);
    if (isQuestion) qno += 1;
    return { ...item, type, index, qno: isQuestion ? qno : 0 };
  });
}

module.exports = { db, demoItems, ITEM_TYPES, QUESTION_TYPES, normalizeItems };
```

在 `server.js` 里加"计划"函数：

```js
const store = require('./db');

function parseSession(session) {
  const items = store.normalizeItems(JSON.parse(session.items_json || '[]'));
  const units = items.filter((i) => i.type !== 'message');
  return { items, units };
}

function computeAction(session) {
  const { units } = parseSession(session);
  const done = store.db.prepare(
    'SELECT COUNT(DISTINCT unit_index) AS n FROM responses WHERE session_id = ?'
  ).get(session.id).n;
  if (done >= units.length) return null;

  const unit = units[done];
  const presented = Date.parse(session.pending_presented_at || new Date().toISOString());
  const wait = Number(unit.limits?.wait || 0) * 1000;
  return {
    itemId: unit.id,
    type: unit.type,
    title: unit.title,
    body: unit.body || '',
    min: unit.min,
    max: unit.max,
    availableAtMs: wait > 0 ? presented + wait : 0,
    nowMs: Date.now(),
    qno: unit.qno
  };
}
```

**注意**：这里用 `COUNT(DISTINCT unit_index)`，而不是 `COUNT(*)`。因为将来题组一次提交会写多行，按行数会算错进度。

> 【方法】进度统计要用"作答单元"而不是"行数"。表结构里保留 `unit_index`，就是为这个。

## 5. Step 4：三个 API

### 5.1 `GET /api/bootstrap?q=...&session=...`

```js
function handleBootstrap(url, res) {
  const code = (url.searchParams.get('q') || '').trim();
  const sid = (url.searchParams.get('session') || '').trim();
  const q = store.db.prepare('SELECT * FROM questionnaires WHERE id = ?').get(code);
  if (!q) return sendJson(res, 404, { error: 'questionnaire_not_found' });

  let session = sid ? store.db.prepare('SELECT * FROM sessions WHERE id = ?').get(sid) : null;
  if (session && session.questionnaire_id !== code) session = null;
  if (!session || session.status !== 'in_progress') {
    return sendJson(res, 200, { questionnaireTitle: q.title, session: null, messages: [], action: null });
  }
  const messages = store.db.prepare(
    'SELECT id, role, content, item_id FROM messages WHERE session_id = ? ORDER BY id'
  ).all(session.id);
  return sendJson(res, 200, {
    questionnaireTitle: q.title,
    session,
    messages,
    action: computeAction(session)
  });
}
```

### 5.2 `POST /api/session {q}`

```js
async function handleCreateSession(req, res) {
  const body = await readJsonBody(req);
  const q = store.db.prepare('SELECT * FROM questionnaires WHERE id = ?').get(String(body.q || ''));
  if (!q) return sendJson(res, 404, { error: 'questionnaire_not_found' });

  const id = crypto.randomUUID();
  const now = new Date().toISOString();
  const items = JSON.parse(q.items_json);
  const seq = store.db.prepare(
    'SELECT COALESCE(MAX(seq), 0) + 1 AS n FROM sessions WHERE questionnaire_id = ?'
  ).get(q.id).n;

  store.db.prepare(`
    INSERT INTO sessions (id, questionnaire_id, seq, status, items_json, started_at, pending_presented_at)
    VALUES (?, ?, ?, 'in_progress', ?, ?, ?)
  `).run(id, q.id, seq, JSON.stringify(items), now, now);

  // 发出第一个作答单元之前的消息
  const firstUnit = store.normalizeItems(items).find((i) => i.type !== 'message');
  let seqMsg = 0;
  for (const item of items) {
    if (firstUnit && item.id === firstUnit.id) break;
    if (item.type !== 'message' || !String(item.text || '').trim()) continue;
    store.db.prepare(`
      INSERT INTO messages (session_id, role, content, seq, created_at, item_id)
      VALUES (?, 'assistant', ?, ?, ?, ?)
    `).run(id, item.text, ++seqMsg, now, item.id);
  }

  const session = store.db.prepare('SELECT * FROM sessions WHERE id = ?').get(id);
  return sendJson(res, 200, {
    questionnaireTitle: q.title,
    session,
    messages: store.db.prepare('SELECT id, role, content, item_id FROM messages WHERE session_id = ? ORDER BY id').all(id),
    action: computeAction(session)
  });
}
```

### 5.3 `POST /api/step`

```js
async function handleStep(req, res) {
  const body = await readJsonBody(req);
  const session = store.db.prepare('SELECT * FROM sessions WHERE id = ?').get(String(body.sessionId || ''));
  if (!session) return sendJson(res, 404, { error: 'session_not_found' });
  if (session.status !== 'in_progress') return sendJson(res, 409, { error: 'session_closed' });

  const action = computeAction(session);
  if (!action) return sendJson(res, 409, { error: 'session_closed' });

  // 幂等：只接受当前题
  if (body.itemId && String(body.itemId) !== action.itemId) {
    return sendJson(res, 200, { ignored: true, action });
  }

  const now = Date.now();
  if (action.availableAtMs && now < action.availableAtMs) {
    return sendJson(res, 400, {
      error: 'too_early',
      availableAtMs: action.availableAtMs,
      nowMs: now
    });
  }

  // 最小校验：打分题
  if (action.type === 'rating') {
    const v = Number(body.value);
    const min = Number(action.min) || 1;
    const max = Number(action.max) || 5;
    if (!Number.isInteger(v) || v < min || v > max) {
      return sendJson(res, 400, { error: 'invalid_answer' });
    }
    const answeredAt = new Date(now).toISOString();
    store.db.prepare(`
      INSERT INTO responses
        (session_id, item_id, unit_index, value, value_text, option_label, presented_at, answered_at, elapsed_ms)
      VALUES (?, ?, ?, ?, '', ?, ?, ?, ?)
    `).run(
      session.id, action.itemId,
      store.db.prepare('SELECT COUNT(DISTINCT unit_index) AS n FROM responses WHERE session_id = ?').get(session.id).n,
      v, `${v} 分`, session.pending_presented_at, answeredAt,
      Number.isFinite(Number(body.elapsedMs)) ? Number(body.elapsedMs) : null
    );
    // 用户回显
    store.db.prepare(`
      INSERT INTO messages (session_id, role, content, seq, created_at, item_id)
      VALUES (?, 'user', ?, (SELECT COALESCE(MAX(seq), 0) + 1 FROM messages WHERE session_id = ?), ?, ?)
    `).run(session.id, `我的选择：${v} 分`, session.id, answeredAt, action.itemId);
  }

  // 计算下一单元并更新呈现时刻
  const updated = store.db.prepare('SELECT * FROM sessions WHERE id = ?').get(session.id);
  const next = computeAction(updated);
  if (!next) {
    store.db.prepare("UPDATE sessions SET status = 'completed' WHERE id = ?").run(session.id);
  } else {
    store.db.prepare('UPDATE sessions SET pending_presented_at = ? WHERE id = ?')
      .run(new Date(now).toISOString(), session.id);
  }
  const after = store.db.prepare('SELECT * FROM sessions WHERE id = ?').get(session.id);
  return sendJson(res, 200, {
    session: after,
    action: computeAction(after),
    messages: store.db.prepare('SELECT id, role, content, item_id FROM messages WHERE session_id = ? ORDER BY id').all(session.id)
  });
}
```

`readJsonBody` 的最小实现：

```js
function readJsonBody(req, maxBytes = 4 * 1024 * 1024) {
  return new Promise((resolve, reject) => {
    let size = 0, done = false;
    const chunks = [];
    req.on('data', (c) => {
      if (done) return;
      size += c.length;
      if (size > maxBytes) { done = true; reject(new Error('body_too_large')); return; }
      chunks.push(c);
    });
    req.on('end', () => {
      if (done) return;
      try { resolve(chunks.length ? JSON.parse(Buffer.concat(chunks).toString('utf8')) : {}); }
      catch { resolve({}); }
    });
    req.on('error', reject);
  });
}
```

`public/assets/chat.js`：

```js
'use strict';
const params = new URLSearchParams(location.search);
const q = (params.get('q') || '').trim();
const KEY = `expchat_session_${q}`;
const $stream = document.getElementById('stream');
const $card = document.getElementById('card');

let state = { session: null, action: null, busy: false };

async function api(path, options = {}) {
  const res = await fetch(path, {
    ...options,
    headers: { 'Content-Type': 'application/json', ...(options.headers || {}) }
  });
  const data = await res.json().catch(() => ({}));
  if (!res.ok) {
    const err = new Error(data.message || data.error || `HTTP ${res.status}`);
    err.data = data;
    err.status = res.status;
    throw err;
  }
  return data;
}

function addMessage(text, role = 'assistant') {
  const div = document.createElement('div');
  div.className = `msg ${role}`;
  div.textContent = text;
  $stream.appendChild(div);
  window.scrollTo(0, document.body.scrollHeight);
}

function renderAction(action) {
  $card.innerHTML = '';
  if (!action) { addMessage('实验已完成，感谢参与。'); return; }

  const title = document.createElement('h2');
  title.textContent = action.title || '';
  $card.appendChild(title);

  if (action.body) {
    const p = document.createElement('p');
    p.textContent = action.body;
    $card.appendChild(p);
  }

  const row = document.createElement('div');
  for (let v = action.min || 1; v <= (action.max || 5); v += 1) {
    const btn = document.createElement('button');
    btn.textContent = String(v);
    btn.onclick = () => submit(v);
    row.appendChild(btn);
  }
  $card.appendChild(row);
}

async function submit(value) {
  if (state.busy || !state.action) return;
  state.busy = true;
  try {
    const data = await api('/api/step', {
      method: 'POST',
      body: JSON.stringify({
        sessionId: state.session.id,
        itemId: state.action.itemId,
        value,
        elapsedMs: Date.now() - (state.action.nowMs || Date.now())
      })
    });
    if (data.session) state.session = data.session;
    state.action = data.action;
    if (data.action && data.action.type === 'rating') renderAction(data.action);
    else {
      $card.innerHTML = '';
      addMessage('实验已完成，感谢参与。');
    }
  } catch (err) {
    if (err.status === 400 && err.data && err.data.error === 'too_early') {
      addMessage('还不能提交，请稍候。');
    } else {
      addMessage(`提交失败：${err.message}`);
    }
  } finally {
    state.busy = false;
  }
}

async function boot() {
  const sid = localStorage.getItem(KEY) || '';
  const boot = await api(`/api/bootstrap?q=${encodeURIComponent(q)}&session=${encodeURIComponent(sid)}`);
  if (boot.session) {
    state.session = boot.session;
    boot.messages.forEach((m) => addMessage(m.content, m.role));
    state.action = boot.action;
    if (state.action) renderAction(state.action);
    else addMessage('实验已完成，感谢参与。');
    return;
  }

  const created = await api('/api/session', {
    method: 'POST',
    body: JSON.stringify({ q })
  });
  state.session = created.session;
  localStorage.setItem(KEY, created.session.id);
  created.messages.forEach((m) => addMessage(m.content, m.role));
  state.action = created.action;
  if (state.action) renderAction(state.action);
}

boot().catch((err) => addMessage(`打不开实验：${err.message}`));
```

验收：

1. 打开 `http://localhost:3000/chat?q=test0001`；
2. 看到欢迎语和 1–5 按钮；
3. 点 4，库里新增一行；
4. 刷新，消息回放、当前题不重复；
5. 再点一次（如果已答完，应该显示结束；如果还没答完，重复提交被 ignored）。

**注意**：这个最小版本没有"已答题卡回放为只读"，刷新后只显示消息 + 当前题。下一步再加 `replay`。

## 7. Step 6：管理端最小闭环

先不做可视化编辑器，做一个"能改内容"的最小管理端：

- `GET /api/admin/questionnaire?id=test0001` 返回题目 JSON；
- `POST /api/admin/questionnaire/update` 保存；
- 页面用一个 `<textarea>` 编辑 JSON，点保存。

```html
<!-- public/admin.html -->
<textarea id="json" rows="20" style="width:100%"></textarea>
<button id="save">保存</button>
<script>
  let token = sessionStorage.getItem('token') || '';
  async function load() {
    const r = await fetch('/api/admin/questionnaire?id=test0001', {
      headers: { Authorization: `Bearer ${token}` }
    });
    document.getElementById('json').value = JSON.stringify(await r.json(), null, 2);
  }
  document.getElementById('save').onclick = async () => {
    const items = JSON.parse(document.getElementById('json').value);
    const r = await fetch('/api/admin/questionnaire/update', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
      body: JSON.stringify({ id: 'test0001', items })
    });
    alert(r.ok ? '已保存' : '保存失败');
  };
  load();
</script>
```

**关键验收（架构试金石）**：

1. 用 A 会话答到一半；
2. 在管理端把题目标题改掉；
3. 刷新 A 会话：A 仍看到旧标题（快照生效）；
4. 新建 B 会话：B 看到新标题。

如果 A 看到了新标题，说明你没有快照，而是实时关联了问卷——回到第 5.2 步检查 `sessions.items_json`。

> 【方法】这是整个架构最重要的验收之一。它证明"模板/实例隔离"真的生效，而不只是写在文档里。

## 8. Step 7：最小导出

先用 CSV（Excel 能打开），再换 xlsx。

```js
function toCsv(rows, headers) {
  const esc = (v) => `"${String(v ?? '').replace(/"/g, '""')}"`;
  return [headers.map(esc).join(','), ...rows.map((r) => headers.map((h) => esc(r[h])).join(','))].join('\r\n');
}
```

```js
function handleExport(res, questionnaireId) {
  const rows = store.db.prepare(`
    SELECT s.seq AS 编号, r.item_id AS 题目, r.value AS 分值,
           r.option_label AS 作答, r.presented_at AS 呈现时间,
           r.answered_at AS 作答时间, r.elapsed_ms AS 耗时毫秒
    FROM responses r
    JOIN sessions s ON s.id = r.session_id
    WHERE s.questionnaire_id = ?
    ORDER BY s.seq, r.unit_index
  `).all(questionnaireId);
  const csv = toCsv(rows, ['编号', '题目', '分值', '作答', '呈现时间', '作答时间', '耗时毫秒']);
  res.writeHead(200, {
    'Content-Type': 'text/csv; charset=utf-8',
    'Content-Disposition': `attachment; filename="export.csv"`
  });
  res.end('\uFEFF' + csv); // BOM：Excel 正确识别 UTF-8
}
```

验收：下载 → Excel 打开 → 中文不乱码 → 一题一行 → 时间列可排序。

之后再换 `xlsx.js` 的手写 OOXML 或 `exceljs`。先 CSV 的好处是：导出的**列口径**先定下来，格式可以后换。

## 9. Step 8：鉴权与安全基线

最小管理端也要有登录，否则公网一放，谁都能改问卷、看数据。

最小实现：

1. `users` 表：`id, username, pass_hash, salt, role, token_epoch`；
2. `scrypt(password, salt)` 存哈希；
3. 登录成功签发 `payload.signature`（HMAC-SHA256）；
4. `requireUser` 校验签名、过期、`token_epoch`；
5. 管理 API 先鉴权，再按 `owner_id` 过滤数据；
6. 登录/建会话加限流；
7. 静态服务防路径穿越；
8. `readJsonBody` 限 4MB；
9. 安全头（CSP、`X-Content-Type-Options`、`frame-ancestors` 等）。

**不要**自己发明加密算法：用 `crypto.scrypt`、`crypto.createHmac`、`crypto.timingSafeEqual` 这些标准原语。

验收：

```bash
# 未登录访问管理 API → 401
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:3000/api/admin/questionnaire?id=test0001

# 错误密码 → 401
curl -s -X POST http://localhost:3000/api/auth/login \
  -H "Content-Type: application/json" -d '{"username":"admin","password":"wrong"}'
```

> 【方法】安全基线不是"以后加"，而是"管理端一存在就要有"。尤其是数据里含被试作品与编号。

## 10. Step 9：自检脚本

`scripts/check.js` 的最小骨架：

```js
'use strict';
const assert = require('node:assert');
const fs = require('node:fs');
const { spawn } = require('node:child_process');
const { DatabaseSync } = require('node:sqlite');

const BASE = 'http://127.0.0.1:3100';
const PORT = 3100;
fs.mkdirSync('.tmp', { recursive: true });

async function json(path, options = {}) {
  const res = await fetch(BASE + path, {
    ...options,
    headers: { 'Content-Type': 'application/json', ...(options.headers || {}) }
  });
  const body = await res.json().catch(() => ({}));
  return { status: res.status, body };
}

async function main() {
  // 用独立端口 + 独立库，避免污染开发库
  const child = spawn(process.execPath, ['server.js'], {
    env: { ...process.env, PORT: String(PORT), DB_PATH: '.tmp/check.db' },
    stdio: 'ignore'
  });
  try {
    // 等服务起来
    for (let i = 0; i < 50; i += 1) {
      try { if ((await json('/api/health')).status === 200) break; } catch { /* retry */ }
      await new Promise((r) => setTimeout(r, 100));
    }

    const created = await json('/api/session', {
      method: 'POST', body: JSON.stringify({ q: 'test0001' })
    });
    assert.equal(created.status, 200);
    const sid = created.body.session.id;

    const early = await json('/api/step', {
      method: 'POST',
      body: JSON.stringify({ sessionId: sid, itemId: 'q1', value: 4 })
    });
    // 若 q1 配了 wait，这里应是 400；没配则应 200
    console.log('step status =', early.status);

    // 时间旅行：把呈现时刻回拨 10 分钟，再提交
    const db = new DatabaseSync('.tmp/check.db');
    db.prepare('UPDATE sessions SET pending_presented_at = ? WHERE id = ?')
      .run(new Date(Date.now() - 10 * 60 * 1000).toISOString(), sid);
    db.close();

    const ok = await json('/api/step', {
      method: 'POST',
      body: JSON.stringify({ sessionId: sid, itemId: 'q1', value: 4, elapsedMs: 1000 })
    });
    assert.equal(ok.status, 200);

    const dup = await json('/api/step', {
      method: 'POST',
      body: JSON.stringify({ sessionId: sid, itemId: 'q1', value: 5 })
    });
    assert.equal(dup.body.ignored, true);

    console.log('ALL PASS');
  } finally {
    child.kill();
  }
}

main().catch((err) => { console.error(err); process.exitCode = 1; });
```

验收：

```bash
npm run check
# ALL PASS
```

> 【方法】自检要从第一天就写。它不是为了"测试覆盖率"，而是为了让你敢改。没有自检，改一个字段要手动点十分钟。

## 11. Step 10：打包与启动器

最小便携包：

```text
dist/portable.zip
  ├─ node.exe
  ├─ server.js / db.js / package.json
  ├─ public/
  ├─ data.db（可选，快照）
  └─ 启动.bat
```

`启动.bat`（纯 ASCII，避免 Windows 代码页乱码）：

```bat
@echo off
cd /d "%~dp0"
start "" "%~dp0node.exe" server.js
timeout /t 2 >nul
start "" http://localhost:3000/
```

更完整的启动器要处理：

- 旧实例还在跑 → 先结束；
- 端口被占 → 换空闲端口；
- 二维码/入口地址跟着端口走；
- 出错时把日志写到文件，而不是黑框一闪而过。

验收：在**没装 Node** 的 Windows 机器上双击 `启动.bat`，浏览器能打开管理端。

## 12. 时间预算与 commit 序列

### 12.1 三种节奏

| 节奏 | 做到哪 | 适合 |
|---|---|---|
| 90 分钟 | Step 1–4：静态服务、库、三个 API、curl 跑通 | 验证技术栈 |
| 1 天 | Step 1–6：加被试端页面、管理端 JSON 编辑、快照验收 | 最小可用 Demo |
| 3 天 | Step 1–10：加导出、鉴权、自检、打包 | 预实验可用骨架 |

不要第一天就做 10 种题型。**先让一条最窄的路径真实跑通。**

### 12.2 建议的 commit 序列

```text
1  chore: init repo, README, gitignore
2  feat: static server + /api/health
3  feat: sqlite schema + idempotent seed
4  feat: item model + session plan
5  feat: subject APIs (bootstrap/session/step)
6  feat: subject chat page for rating item
7  feat: replay answered items on refresh
8  feat: admin json editor + snapshot isolation
9  feat: csv export
10 feat: scrypt login + bearer token
11 test: platform check with time travel
12 feat: portable package + start script
13 docs: README + deploy notes
14 chore: release v0.1.0
```

每个 commit 都应该能独立运行、通过 `npm run check`。不要"攒一大坨再提交"。

## 13. 常见坑（按出现频率排序）

| # | 坑 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | 把实验流程硬编码成 `if (step === 3)` | 改流程就要改代码 | 题目数组 + 状态机 |
| 2 | 前端 `setTimeout` 当门控 | 刷新/改时间就绕过 | 服务端时间戳 + 提交校验 |
| 3 | 不做题目快照 | 改问卷污染进行中会话 | `sessions.items_json` |
| 4 | 提交不校验 `itemId` | 迟到请求记到下一题 | 幂等忽略 |
| 5 | 到点自动提交空答案 | 数据里全是空值 | 有内容才自动提交，无内容停在题上 |
| 6 | 正确答案下发前端 | 被试可直接看 | 只在服务端比对 |
| 7 | 不做恢复 | 刷新就重来，流失高 | localStorage + bootstrap |
| 8 | 进度按 `COUNT(*)` 算 | 题组多行导致跳题 | 按 `unit_index` 去重 |
| 9 | 种子不幂等 | 每次启动多一份问卷 | `INSERT OR IGNORE` |
| 10 | 只备份 `data.db` | WAL 里的数据丢失 | 三件套一起备，或先停服务 |
| 11 | 提交 `data.db` | 被试数据进 git | `.gitignore` + 提交前检查 |
| 12 | 只测 happy path | 预实验现场翻车 | 覆盖提前提交/刷新/重复提交/超时 |
| 13 | 一开始做 10 种题型 | 永远跑不通端到端 | 先做 1 种，垂直切片 |
| 14 | 文案写死在代码里 | 改文案要找开发 | `seed-content.js` + 管理端 |
| 15 | 没有"完成定义" | 以为做完了，其实没验收 | 每条需求带验收口径 |

## 14. 骨架完成后的增量路线

按这个顺序加，每一步都能独立验收：

1. **更多题型**：文本 → 单选/多选 → 题组 → 排序 → 页面类（gate/confirm/debrief）；
2. **参数系统**：题型白名单 + 钳位 + 编辑器参数区；
3. **消息节奏**：思考面板、打字机、流式速度；
4. **清屏点**：服务端 `clear_seq`；
5. **恢复与作废**：恢复窗口、超时作废、释放设备；
6. **重做**：打分题就地更新；
7. **管理端可视化编辑器**：大纲、拖拽、批量插入、模板；
8. **预览**：内存会话 + iframe + 倍速/跳题；
9. **导出**：汇总/逐题/明细三 sheet；
10. **多用户**：角色、数据隔离、单设备；
11. **分发**：二维码、便携包、上线包；
12. **质量**：两层自检、截图走查、并发探针。
