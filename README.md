# 对话式问卷 / 实验平台

一个**零第三方依赖**的对话式问卷系统：被试在手机上像聊天一样逐题完成问卷，研究者在管理端编排题目、手机预览、查看数据并导出 Excel。

系统采用「一切皆题目」的模型：实验是可复用的题目模板，问卷是一条链接加一列题目；材料、量表、创作、反馈、结束说明都是题目。

## 特点

- **零依赖、零安装**：使用 Node 内置的 `node:sqlite`，不需要 `npm install`，也不需要单独安装数据库。
- **单进程、单文件数据库**：`node server.js` 一条命令启动，默认监听 3000 端口。
- **手机扫码作答**：每份问卷都有短码与二维码；被试扫码直达作答页，管理端可保存二维码海报。
- **管理端编排**：问卷 / 模板编辑、题目大纲、手机端实时预览、插入整组题目、批量插入打分题。
- **10 种题型**：打分、单选、多选、文本、排序、题组，以及材料消息、知情同意页、阅读确认页、结束说明页。
- **计时门控服务端权威**：强制阅读、最短提交、最长作答、呈现前清屏均由服务端校验，不依赖前端计时。
- **AI 思考面板**：消息题可配置思考稿与思考时长，按流式节奏逐字呈现。
- **数据即用**：每次作答带呈现 / 作答时间戳与耗时；一键导出 Excel（汇总 / 逐题作答 / 作答明细）。
- **刷新可恢复**：逐题提交、断网重试；刷新或重开页面可在恢复窗口内续做。
- **账号与权限**：管理员 / 普通用户；同一账号同时只允许一台设备在线。

## 快速开始

要求 **Node.js >= 22.13.0**（`node:sqlite` 的硬性下限）。

```bash
# 方式一：指定初始管理员密码（至少 10 位）
ADMIN_PASSWORD='请换成强密码123!' node server.js

# 方式二：不指定，首次启动生成一次性随机密码并打印到日志
node server.js
```

启动后打开 <http://localhost:3000/>，根路径就是管理端；未登录时显示登录卡片。

- 管理员账号：`admin`
- 初始密码：来自 `ADMIN_PASSWORD`；未设置则随机生成，**只打印一次**。
- 首次登录后请立即在「个人设置」中修改密码。
- 首次启动会创建一套**中性示例问卷**（产品体验调查），可直接试用，也可以在管理端删除。

被试端入口：`/chat?q=<问卷短码>`。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `ADMIN_PASSWORD` | 随机 | 首次建库时 `admin` 的初始密码；至少 10 位。建库后修改此变量不会改已有密码 |
| `DB_PATH` | `./data.db` | SQLite 文件路径；可指向独立数据目录 |
| `ALLOW_REGISTRATION` | `1` | 是否允许普通账号自助注册；设为 `0` / `false` / `off` 关闭 |
| `MAX_QUESTIONNAIRES_PER_USER` | `10` | 普通账号问卷数量上限（管理员可在全局设置中调整） |
| `MAX_EXPERIMENTS_PER_USER` | `10` | 普通账号模板数量上限（管理员可在全局设置中调整） |

## 数据与备份

- 数据库文件：`data.db`（以及运行时的 `data.db-wal`、`data.db-shm`）。
- 三个文件已加入 `.gitignore`，**不要提交到 git**。
- 备份时请把三个文件一起复制；恢复时也一起放回。
- 想彻底重来：停止服务，移走三个数据库文件，重新启动即可建新库。

## 目录结构

```text
server.js             服务端入口（HTTP 路由装配 + 启动）
src/                  服务端模块：config / http / auth / session / preview / report / routes
db.js                 数据层：建表、种子、题目归一化、存取
seed-demo.js          中性示例种子（首次启动创建示例模板 / 问卷）
xlsx.js               零依赖的 XLSX 写出
public/               管理端与被试端（无构建，原生 HTML/CSS/JS）
  admin.html          管理端外壳
  chat.html           被试端页面
  assets/             前端脚本与样式
  assets/admin/       管理端 ES Module（main / core / features / pages）
vendor/qrcode.js      二维码生成
```

## 说明

- 本仓库不包含任何真实研究数据或实验材料；`seed-demo.js` 只是一套中性的产品体验示例。
- 如果要用于正式研究，请在管理端自行创建模板与问卷，并确认知情同意、数据保存与伦理要求。
- 管理员密码、数据库文件和备份都属于敏感信息，请勿提交到公开仓库。
